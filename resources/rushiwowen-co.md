# RuShiWoWen 如是我闻

**URL:** https://rushiwowen.co/en

**Language:** Chinese source texts; English and Japanese reading layers

**Region:** Global

## Summary

RuShiWoWen is a public web reader and search interface for Chinese Buddhist texts derived from the CBETA canon. It provides stable work URLs and full-text search so readers can locate and read canonical Chinese passages online.

The site also offers English and Japanese AI-assisted reading layers. These layers are presented as reading aids rather than authoritative translations, while the Chinese source text remains the reference layer. The platform is therefore useful for Chinese Buddhist studies, comparative reading, and digital-humanities exploration of Buddhist texts.
